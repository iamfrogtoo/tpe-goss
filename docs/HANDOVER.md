# 專案交接文件 (HANDOVER)

## 1. 專案目標與技術棧
本專案 (TPE GOSS) 主要目標為建立即時航班狀態與排程查詢系統，提供地勤人員或相關使用者快速、準確的航班進場、離場、與登機門資訊。
**技術棧：**
- **前端 Web App**：Next.js 16 (React 19), TypeScript, Tailwind CSS v4。
- **後端資料收集 (Tracker)**：Python 爬蟲腳本 (負責抓取即時航班資料並自動寫入試算表)。
- **資料儲存/同步**：Google Sheets API 以及本地 JSON 檔案。

## 2. 嚴格的環境架構限制與部署邏輯
**【重要】** 關於本專案的三節點架構（本地開發、Linux 爬蟲伺服器、前端 Vercel）與詳細的指令部署規範，**請全面參考 `AI_RULES.md` 檔案**。

## 3. 已完成進度與近期功能擴充

### 航班狀態與資料庫優化 (Backend)
- **擴展 10 級距資料結構**：成功將 `tracker_inbound.py`, `tracker_outbound.py` 與 `tracker_schedule.py` 中的表單結構由基礎 5 欄擴展至 10 欄，新增並抓取包含：航廈、報到櫃台、行李轉盤、機型 (AC Type) 以及註冊機身編號。
- **機型與機身編號對齊**：實作 `ground_data.py` 和 `aircraft_db.py` 機制，能夠即時解析官方資料並配對精確的出境/入境機身註冊編號 (Registration Number) 與機型，提高地勤實用性。
- **過濾重複與共享航班 (Codeshare Deduplication)**：因應機場端出現多重同一時間、同一機坪但不同代號之問題，於 Python `tracker` 端設定「時間+機坪」為單一 Unique Key 的嚴謹去重複邏輯，解決了長久以來版面被洗板與資料重疊的問題。
- **修復 Python 常駐衝突與建立閃電部屬 (Deployment Script)**：開發了本機端一鍵發布指令 (`deploy_script.py` based on `paramiko`)，可自動透過 SSH 連線至 Linux 遠端伺服器 (192.168.31.19)，強制斬斷 (killall) 舊有打架的多重背景 Tracker 執行個體，隨後安全上傳新版代碼與 `local_aircraft_db.json` 並確保 `nohup` 背景重新掛載。完全解決了 Google Sheets 新舊資料交錯閃爍的異常問題。

### 前端 UI 渲染與呈現 (Frontend)
- **前端讀取邏輯回歸 Google Sheets 生態圈**：由於 Tracker 伺服器常駐於遠端 Linux 而前端在本機 (或雲端) 運行，因此取消了原先的本地 JSON 取代寫法，重新還原並優化為讀取 Google Sheets CSV，保證資料雙向溝通穩定。
- **航班時刻表 (Schedule/page.tsx) 視覺升級**：將最新獲取的航廈 (Terminal)、報到櫃台 (Counter)、行李轉盤 (Baggage Claim)、機型與機身編號，重新編排並放入歷史/全日排班搜尋列表卡片內，以動態、具顏色的標籤清楚顯示，大大增加查詢效率。

### 系統升級與自動化彙報 (v2.6)
- **自動化每日航情彙總 (Daily Export)**：新增 `export_daily_report.py`，支援於每日指定時段自動將整日百筆航班陣列（包含客機與貨機）進行去重複疊加與梳理，匯出為 14 欄標準化之營運紀錄並寫入專屬表單，完美累積歷史大數據。
- **機型家族與星宇防呆排除**：升級 `tracker_inbound.py` 之機身辨識演算法，現已能智慧將 A320 系列家族化作無縫相容（免除過敏的機型變更警報），並強制為星宇航空 (JX/SJX) 設定波音客機攔截機制，將誤判率與錯誤訊息大幅降低。
- **雙欄對稱與時間雙顯**：登機門模組與單一航班介面全面套用「全境對稱式」排版（獨立切割左側進場 / 右側離場）。即時離場與航班查詢卡片如今均能高亮度顯示「動態機身編號」及「表定/預計」雙重時間。

### 介面優化與錯誤修復 (v2.63)
- **去除錯誤訊息與代碼防呆**：修正了順豐航空 (O3) 的正則表達式誤判，並透過 `ICAO_TO_IATA` 降級轉換矩陣，自動將機場端外籍客貨機 (如 VN, CAL) 轉為內存的 IATA 格式，100% 尋回「即時離場」頁面遺失的遙控接駁坪資料。
- **過境航班 (Transit) 視覺重構**：於登機門 (Gate) 詳情頁，為進出相同班號的過境飛機設計了嶄新的「置中呼號顯示區塊」，並移除了時間標籤上冗餘的 `:00` 秒數，視覺清爽對齊。
- **廢除留言板功能適應靜態唯讀雲端 (Vercel)**：移除了因 Vercel 唯讀系統限制而產生錯誤訊息的留言板功能，專注重組與打磨純粹的航班資料牆呈現。
