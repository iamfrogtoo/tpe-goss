# 伺服器端全自動設置指南

## 目標

讓伺服器自己完成所有工作，不需要本地端保持運行！

## 重要提示

clone 下來的倉庫根目錄就是 `goss-v4`，裡面已經有 `goss-v4` 子目錄了！

## 步驟

### 1. 在伺服器上設置 git 倉庫

```bash
# SSH 登入伺服器
ssh xinzhi@192.168.31.19

# 先停止正在運行的 bridge_v4.py
pkill -f bridge_v4.py

# 先備份現有數據
cd ~
mv goss-v4 goss-v4.old

# 從 GitHub clone（這會創建 goss-v4 目錄）
git clone https://github.com/iamfrogtoo/tpe-goss.git goss-v4

# 進入正確的目錄（goss-v4/goss-v4）
cd goss-v4/goss-v4

# 把備份的數據庫複製回來
cp ~/goss-v4.old/goss_v4.db .

# 重新啟動 bridge_v4.py
nohup python3 -u bridge_v4.py >> bridge.log 2>&1 &
```

### 2. 在伺服器上測試 push_to_github.py

```bash
cd ~/goss-v4/goss-v4

# 先測試一次
python3 push_to_github.py
```

### 3. 設置 cron 定時任務

```bash
# 編輯 crontab
crontab -e

# 添加以下行（每分鐘執行一次）
* * * * * cd /home/xinzhi/goss-v4/goss-v4 && python3 push_to_github.py >> push.log 2>&1
```

### 4. 確認日誌

```bash
# 查看 bridge 日誌
tail -f ~/goss-v4/goss-v4/bridge.log

# 查看 push 日誌
tail -f ~/goss-v4/goss-v4/push.log
```

## 完成！

這樣就全自動了：
- ✅ 伺服器上的 `bridge_v4.py` 收集數據
- ✅ 伺服器上的 `push_to_github.py` 每分鐘自動推送
- ✅ Vercel 自動部署
- ✅ 前端從 CDN 讀取數據

不需要本地端保持運行！
