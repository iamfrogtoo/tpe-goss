# TPE GOSS v4 伺服器快速設置指南

## 重要說明

伺服器上的 `~/goss-v4` 目錄**不是** git 倉庫，我們需要調整方案。

## 推薦方案（最簡單）

### 方案 A：本地端定時從伺服器拉取數據（推薦）

這個方案最簡單，不需要在伺服器上設置 git。

#### 步驟：

1. **在伺服器上**：只需要運行 `bridge_v4.py`（已經在運行了）
2. **在本地端**：創建一個腳本定時從伺服器下載數據庫，導出並推送到 GitHub

---

### 方案 B：在伺服器上設置完整的 git 倉庫

如果你想在伺服器上直接推送，需要先把伺服器上的目錄變成 git 倉庫。

#### 步驟：

```bash
# 在伺服器上執行
ssh xinzhi@192.168.31.19

# 先備份現有數據
cd ~
cp -r goss-v4 goss-v4.backup

# 刪除舊目錄，重新 clone
rm -rf goss-v4
git clone https://github.com/iamfrogtoo/tpe-goss.git goss-v4

# 進入目錄
cd goss-v4/goss-v4

# 把備份的數據庫複製回來
cp ~/goss-v4.backup/goss_v4.db .

# 確認 bridge_v4.py 正在運行
ps aux | grep bridge_v4.py

# 如果沒有運行，啟動它
cd ~/goss-v4/goss-v4
nohup python3 -u bridge_v4.py >> bridge.log 2>&1 &
```

然後設置定期執行 `push_to_github.py`：

```bash
# 編輯 crontab
crontab -e

# 添加以下行（每分鐘執行一次）
* * * * * cd /home/xinzhi/goss-v4/goss-v4 && python3 push_to_github.py >> push.log 2>&1
```

## 我推薦使用方案 A

讓我為你創建一個本地端的腳本來定時從伺服器拉取數據。

### 本地端設置（方案 A）

1. 確保可以無密碼 SSH 登入伺服器
2. 創建 `pull_from_server.py` 腳本
3. 設置本地端定時任務

這樣最簡單，不需要改動伺服器上的設置。
