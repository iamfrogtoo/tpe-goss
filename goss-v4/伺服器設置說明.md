# TPE GOSS v4 伺服器設置說明

## 概述

本說明文件介紹如何在 i5 伺服器 (192.168.31.19) 上設置數據同步任務，讓首頁能顯示即時航班數據。

## 架構

- **數據源**：本地樹莓派 ADS-B + OpenSky API
- **數據融合**：`bridge_v4.py`（必須持續運行）
- **數據導出**：`push_to_github.py`（定期執行）
- **數據傳輸**：GitHub + jsdelivr CDN
- **前端顯示**：Next.js 從 CDN 讀取數據

## 伺服器設置步驟

### 1. 確認 bridge_v4.py 正在運行

```bash
# SSH 登入伺服器
ssh xinzhi@192.168.31.19

# 進入專案目錄
cd ~/goss-v4

# 檢查 bridge_v4.py 是否運行
ps aux | grep bridge_v4.py

# 如果沒有運行，啟動它
nohup python3 -u bridge_v4.py >> bridge.log 2>&1 &
```

### 2. 設置 push_to_github.py 定期執行

使用 cron 每 30 秒執行一次（實際上 cron 最小單位是 1 分鐘，我們用腳本實現 30 秒）：

#### 方法一：使用 cron 每分鐘執行（推薦）

```bash
# 編輯 crontab
crontab -e

# 添加以下行（每分鐘執行一次）
* * * * * cd /home/xinzhi/goss-v4 && python3 push_to_github.py >> push.log 2>&1
```

#### 方法二：使用腳本實現 30 秒間隔

創建 `run_push.sh`：

```bash
#!/bin/bash
cd /home/xinzhi/goss-v4
while true; do
    python3 push_to_github.py >> push.log 2>&1
    sleep 30
done
```

設置執行權限並啟動：

```bash
chmod +x run_push.sh
nohup ./run_push.sh >> run_push.log 2>&1 &
```

### 3. 確認 Git 設置

```bash
# 確認在正確的 git 倉庫
cd ~/goss-v4
git status

# 確認遠端倉庫
git remote -v

# 如果需要，設置用戶資訊
git config user.name "Your Name"
git config user.email "your.email@example.com"
```

### 4. 測試手動執行

```bash
cd ~/goss-v4
python3 push_to_github.py
```

檢查輸出，確認：
- 數據成功導出
- Git 提交成功
- 推送到 GitHub 成功

### 5. 確認日誌

```bash
# 查看 bridge 日誌
tail -f bridge.log

# 查看 push 日誌
tail -f push.log
```

## 數據流程

1. `bridge_v4.py` 從樹莓派和 OpenSky 獲取數據，寫入 `live_traffic` 表
2. `push_to_github.py` 每分鐘從 `live_traffic` 表讀取最近 5 分鐘的數據
3. 數據導出為 `public/live_data.json`
4. 提交並推送到 GitHub
5. jsdelivr CDN 自動更新
6. 首頁從 CDN 讀取數據並顯示

## 故障排除

### 問題 1：首頁顯示模擬數據

檢查：
1. `bridge_v4.py` 是否正在運行
2. `live_traffic` 表是否有最新數據（最近 5 分鐘內）
3. `push_to_github.py` 是否定期執行
4. GitHub 上的 `public/live_data.json` 是否更新

### 問題 2：push_to_github.py 失敗

檢查：
1. Git 權限是否正確
2. 網路連線是否正常
3. 查看 `push.log` 日誌

### 問題 3：CDN 數據沒有更新

jsdelivr CDN 可能有快取，最多需要幾分鐘更新。可以嘗試：
- 等待 5-10 分鐘
- 在 URL 後面加版本參數（首頁已經自動加了時間戳）
