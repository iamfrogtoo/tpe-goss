## 解决方案

### 1. 部署独立的FlightRadar24容器

#### 1.1 停止并移除现有FR24相关容器（如果存在）
```bash
docker stop flightradar24 2>/dev/null || true
docker rm flightradar24 2>/dev/null || true
```

#### 1.2 创建新的FlightRadar24容器
```bash
docker run -d \
  --name flightradar24 \
  --restart always \
  --network container:ultrafeeder \
  -e TZ=Asia/Taipei \
  -e BEASTHOST=127.0.0.1 \
  -e BEASTPORT=30005 \
  -e FR24KEY=de528ed33a3c9b26 \
  ghcr.io/sdr-enthusiasts/docker-flightradar24:latest
```

### 2. 容器配置说明
- **网络模式**: `--network container:ultrafeeder` - 共享ultrafeeder容器的网络命名空间
- **数据来源**: `BEASTHOST=127.0.0.1:30005` - 从ultrafeeder的readsb服务获取ADS-B数据
- **FR24密钥**: 使用现有的FR24KEY
