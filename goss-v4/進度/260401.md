### 1. 狀態文本處理函數
```typescript
// 處理狀態文本的函數
const processStatus = (status: string): string => {
    // 輸出原始狀態文本用於調試
    console.log('原始狀態文本:', status);
    
    // 直接檢查狀態文本是否包含特定的英文狀態關鍵詞
    if (status.includes('ON TIME')) {
        console.log('匹配到 ON TIME，返回 準時');
        return '準時';
    } else if (status.includes('SCHEDULE CHANGE')) {
        console.log('匹配到 SCHEDULE CHANGE，返回 時間更改');
        return '時間更改';
    } else if (status.includes('DELAYED')) {
        console.log('匹配到 DELAYED，返回 延誤');
        return '延誤';
    } else if (status.includes('CANCELLED')) {
        console.log('匹配到 CANCELLED，返回 取消');
        return '取消';
    } else if (status.includes('BOARDING')) {
        console.log('匹配到 BOARDING，返回 登機中');
        return '登機中';
    } else if (status.includes('DEPARTED')) {
        console.log('匹配到 DEPARTED，返回 已起飛');
        return '已起飛';
    }
    
    console.log('未匹配到狀態，返回原始狀態:', status);
    return status;
};
```

## 遇到的問題與解決方案

### 1. 狀態文本映射不生效
- **問題描述**：修改代碼後，狀態文本仍然顯示為英文
- **原因**：在解析CSV數據之前對整個文本進行狀態文本替換，但在創建航班對象時仍然直接使用了原始的狀態文本
- **解決方案**：在創建航班對象時調用 `processStatus` 函數處理狀態文本，確保狀態文本映射正確應用到航班對象中

### 2. 亂碼處理
- **問題描述**：狀態文本中包含亂碼字符，如 "�Ǯ�ON TIME"
- **解決方案**：使用 `includes` 方法直接檢查狀態文本是否包含特定的英文狀態關鍵詞，忽略前面的亂碼字符
