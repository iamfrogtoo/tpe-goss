# 天线活动状态监控工具

## 项目简介

本工具用于实时监测天线的运行状态，能够全天候自动监控天线是否保持在活动状态，并在检测到异常时发送告警通知。

### 主要功能

- **实时状态监测**：持续检查天线的信号强度和工作状态
- **自动告警**：当检测到天线异常时，通过邮件或Webhook发送告警通知
- **数据可视化**：提供直观的用户界面，显示实时状态、历史数据和告警记录
- **历史数据存储**：将状态数据和告警记录存储到SQLite数据库
- **手动触发检查**：支持手动触发状态检查功能

## 技术架构

- **后端**：Python + Flask
- **前端**：HTML5 + Bootstrap 5 + Chart.js
- **数据库**：SQLite
- **告警方式**：邮件、Webhook (Discord/Slack)

## 安装指南

### 1. 环境要求

- Python 3.7+
- pip

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置文件

编辑 `config.ini` 文件，根据实际情况配置以下内容：

- **Database**：数据库配置
- **Alerts**：告警冷却时间设置
- **Email**：邮件告警配置（可选）
- **Webhook**：Webhook告警配置（可选）

### 4. 启动服务

```bash
python app.py
```

服务将在 `http://0.0.0.0:5000` 启动。

## 使用说明

### 1. 访问界面

打开浏览器，访问 `http://localhost:5000` 即可看到监控界面。

### 2. 功能说明

- **状态概览**：显示当前天线状态、信号强度和最后检查时间
- **操作控制**：
  - 立即检查：手动触发一次状态检查
  - 启动监控：开始自动监控（默认每60秒检查一次）
  - 停止监控：停止自动监控
  - 历史时间选择：选择查看不同时间范围的历史数据
- **信号强度历史**：显示信号强度的历史变化趋势
- **告警记录**：显示所有告警记录，可标记告警为已读

### 3. 告警配置

#### 邮件告警

在 `config.ini` 中启用邮件告警：

```ini
[Email]
enabled = true
smtp_server = smtp.example.com
smtp_port = 587
smtp_user = your_email@example.com
smtp_password = your_password
from_email = antenna-monitor@example.com
to_emails = user1@example.com,user2@example.com
```

#### Webhook告警

在 `config.ini` 中启用Webhook告警（支持Discord、Slack等）：

```ini
[Webhook]
enabled = true
url = https://discord.com/api/webhooks/your-webhook-url
```

## 技术实现

### 状态检测

当前版本使用模拟数据进行状态检测。在实际应用中，需要根据具体的天线类型和通信协议，实现真实的状态检测逻辑。例如：

- **网络设备**：通过SNMP或HTTP API检查状态
- **串口设备**：通过串口通信读取状态
- **其他设备**：根据设备的通信协议实现相应的检测逻辑

### 告警逻辑

- 当信号强度低于30%时，发送"inactive"告警
- 当信号强度在30%-70%之间时，发送"weak"告警
- 当检查过程中出现错误时，发送"error"告警
- 告警有5分钟的冷却时间，避免重复告警

### 数据存储

- 使用SQLite数据库存储状态历史和告警记录
- 状态数据保留时间可根据需要调整

## 注意事项

1. **安全性**：配置文件中的密码等敏感信息请妥善保管
2. **性能**：默认监控间隔为60秒，可根据实际需求调整
3. **扩展性**：可根据需要添加更多告警方式或状态检测逻辑
4. **实际应用**：在生产环境中使用时，建议部署为系统服务，并配置自动启动

## 故障排查

- **服务无法启动**：检查端口是否被占用，Python环境是否正确
- **无法发送邮件**：检查邮件服务器配置和网络连接
- **Webhook告警失败**：检查Webhook URL是否正确，网络连接是否正常
- **数据显示异常**：检查数据库文件是否正常，浏览器缓存是否需要清理
