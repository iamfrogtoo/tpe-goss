# TPE GOSS 技術架構

## 專案概覽

**專案名稱**：TPE GOSS (Taoyuan Airport Ground Operations Surveillance System)
**版本**：goss-v4 (SQLite3 架構)
**核心功能**：ADS-B 航機追蹤、數據融合、貨機標註、機坪自動對標

## 三節點架構

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ 本地開發端       │     │ i5 伺服器       │     │ 樹莓派接收端     │
│ - 開發環境       │     │ - 生產環境       │     │ - ADS-B 接收    │
│ - 代碼管理       │ <-> │ - 數據處理       │ <-> │ - 原始數據採集  │
│ - 測試與驗證     │     │ - 資料庫儲存     │     │ - 即時數據傳輸  │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

## 技術堆疊

### 後端
- **語言**：Python 3.x
- **資料庫**：SQLite3 (`goss_v4.db`)
- **核心腳本**：
  - `bridge_v4.py`：數據融合引擎
  - `fetch_tpe_v4.py`：桃機班表抓取
  - `war_room_v4_viewer.py`：戰情室面板
  - `init_db.py`：資料庫初始化
  - `push_to_github.py`：即時數據推送
  - `fetch_opensky_v4.py`：OpenSky API 備援
  - `fetch_fr24_v4.py`：FlightRadar24 數據抓取

### 前端
- **框架**：Next.js
- **部署**：Vercel
- **網址**：tpegoss.com
- **即時數據**：`live_data.json` (透過 GitHub + jsDelivr CDN)

### 數據源
- **主要**：樹莓派 ADS-B 接收機
- **備援**：OpenSky API
- **輔助**：FlightRadar24 API

## 資料庫架構

### 核心表結構
- **flights**：航班基本資訊
- **positions**：航機位置數據
- **schedules**：航班班表
- **aircraft**：機隊資訊
- **runways**：跑道資訊
- **gates**：登機門資訊

## 系統流程

1. **數據採集**：樹莓派接收 ADS-B 訊號
2. **數據融合**：`bridge_v4.py` 整合多源數據
3. **班表匹配**：比對桃園機場班表
4. **資料庫儲存**：SQLite3 持久化
5. **即時推送**：`push_to_github.py` 每分鐘更新
6. **前端顯示**：Next.js 網站展示

## 運行狀態

- **後台進程**：`bridge_v4.py` (數據融合引擎)
- **定時任務**：`push_to_github.py` (每分鐘執行)
- **磁碟使用**：約 20% (11GB / 57GB)
- **資料庫大小**：`goss_v4.db` 約 2.2MB

## 災害復原

- **資料備份**：定期備份 `goss_v4.db`
- **數據冗餘**：OpenSky API 作為備援
- **故障轉移**：本地開發端可臨時接管
